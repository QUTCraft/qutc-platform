# 已知限制与延期项

> 更新日期：2026-08-05。本文只记录已确认、不会伪装成已实现的边界。

| 项目 | 当前行为 | 风险与处置 | 计划 |
| --- | --- | --- | --- |
| Minecraft RCON | `ServerAdapter` 使用明确标识的 Mock；命令仍受白名单、长度和换行校验并写审计 | 不会连接真实服务器，也不会伪报真实执行 | 按产品决定暂缓 |
| AI 模型 | 支持 `disabled`、确定性 Mock 和 OpenAI-compatible；生产环境拒绝 Mock | 比赛环境必须由运维注入 HTTPS Endpoint、API Key 与模型名，并提前校准 | 比赛部署动作 |
| AI 任务执行 | `AgentRun` 先落库为 `queued`，由 API 内单机 worker 原子领取；重启保留 queued，已运行任务标记失败并审计 | 单机 worker 不适合多实例竞争、独立队列和高吞吐长任务 | v0.2：分布式领取/独立队列 |
| 邮件投递 | 邀请邮件仍在邀请请求事务外同步尝试；申请审批结果进入持久化 Outbox，由单机 worker 异步发送，失败退避、禁用降级和 Admin 重试可见 | SMTP 仍可能增加邀请请求耗时；通知 worker 暂为单实例 | v0.2：多实例 worker、Webhook/退信 |
| 限流 | 当前按 API 实例内存计数 | 重启清零，多实例不共享 | 多实例部署前迁移 Redis |
| 多组织 | 已支持可用组织列表、主动切换和用户默认组织偏好；切换会重新校验 active 成员关系、轮换 Refresh Token、绑定目标组织上下文并写审计，登录时无效偏好自动回退 | 组织搜索和跨组织聚合尚未提供 | v0.2+ |
| 内容修订 | 草稿、发布、下线和恢复都会写不可变内容快照；Admin 可查看完整 Markdown 并恢复为新草稿 | 尚未提供行级 diff、导出和定时发布 | v0.2 |
| 资源统计 | 受控管理/门户下载会递增资产计数并记录最近下载时间，Admin 可按资产查询 | 尚未去重访客、异步聚合或提供报表 | v0.2 |
| 内容审核 | `review` 保留模型语义，比赛 MVP 由具有发布权限的角色直接发布 | 不展示不存在的多级审核能力 | v0.2+ |
| 账号安全增强 | 尚无找回密码、邮箱验证、2FA 或 SSO | 比赛账号由受控管理员创建并使用高强度密码 | v0.2+ |
| 前端包体 | Element Plus 主包产生大于 500 KB 的构建告警 | 不影响正确性；弱网首屏仍需继续优化 | 后续拆分依赖 Chunk |

任何演示、答辩或 README 都必须与本表一致。新增限制时，应记录复现条件、影响范围、临时处置和目标版本。
