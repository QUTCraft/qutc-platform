# MVP 验收清单

- [x] 需求范围、MVP 边界、P0/P1/P2 优先级和非目标已冻结。
- [x] 角色、权限名称、范围限制和后台路由访问建议已定义。
- [x] Portal/Admin API 边界、统一响应、错误、分页和安全要求已写入 OpenAPI 与文档。

- [x] 默认门户、后台工作台、API 契约和自定义门户 Manifest 的信息架构已建立。

## B. 公开门户

| 编号 | 场景 | 前置条件 | 通过条件 |
| --- | --- | --- | --- |
| P-01 | 浏览组织门户 | 已有一个发布组织 | 未登录访问首页可看到组织资料、动态、项目、资源和知识库入口。 |
| P-02 | 访问公开项目 | 存在已发布与草稿项目/内容 | Portal 只显示允许公开项目；草稿及内部字段不可见。 |
| P-03 | 资源下载 | 存在公开资源 | Portal 获取服务端签发地址；浏览器不持有存储密钥。 |
| P-04 | 门户故障回退 | 自定义门户加载失败 | 系统回退到默认 MD3 门户，而不是白屏。 |
| P-05 | 通用组织加入入口 | 当前组织不是 QUTCraft | 通用组织申请页不要求游戏 ID、QQ 或白名单字段；成功提示和空错状态不出现 Minecraft 专用文案。 |

## C. 身份、成员与权限

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A-01 | 未认证访问后台 | 返回统一 `401`；前端不展示伪成功数据。 |
| A-02 | 低权限访问管理资源 | 服务端返回 `403`，即使前端手工输入后台 URL。 |
| A-03 | 内容编辑权限 | 编辑者可创建草稿但不能发布。 |
| A-04 | 管理员权限 | 管理员可发布内容、管理成员与审批；操作写入审计。 |
| A-05 | 组织隔离 | A 组织 token 无法读取或操作 B 组织资源。 |
| A-06 | 多组织切换与默认偏好 | 只允许切换到 active 成员关系；切换轮换 Access/Refresh 组织上下文并保存默认组织，偏好失效时安全回退。 |
| A-07 | 成员邀请 | 单个/批量邀请逐项返回；token 只存哈希、接受后不可复用；组织模板只接受白名单变量，SMTP 禁用时仍可复制链接。 |

## D. 内容发布闭环

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| C-01 | 创建草稿 | 管理端创建内容后状态为 `draft`，Portal 不可见。 |
| C-02 | 审核与发布 | 有权限的操作者将内容发布后，Portal 读取到公开摘要。 |
| C-03 | 下线 | 内容下线后从 Portal、公开缓存和检索结果中消失。 |
| C-04 | 冲突与错误 | 重复提交、无权限、非法字段均给出可追踪错误响应。 |
| C-05 | 修订与恢复 | 创建、更新、发布、下线和恢复均形成不可变版本；恢复只生成新草稿，不直接发布；既有内容具有 v1 基线。 |
| C-06 | 下载统计 | 管理端和已发布 Portal 的受控下载递增计数与最近时间；草稿、跨组织或下线资源不能通过公开入口计数。 |

## E. 审核与服务器适配

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| S-01 | 提交申请 | 申请被保存为 `pending`，申请人不会获得管理权限。 |
| S-02 | 通过申请 | 审核员通过申请后，状态变化、操作者和时间被审计。 |
| S-03 | 并发审批 | 第二次处理同一申请返回 `409`，不重复写入审计或通知。 |
| S-04 | 审批结果通知 | 审批事务写入唯一 Outbox；SMTP 成功、失败或禁用均可追踪，失败可手动重排；通知失败不回滚审批事实。 |

## G. 比赛 AI 附加验收

- [x] AI 只能读取当前组织且当前操作者有权读取的知识来源。
- [x] 生成任务具备持久化 queued 状态、单机 worker、取消、配额、超时、引用正文快照和审计；重启保留 queued，中断的 running 明确失败。
- [x] AI 输出不会自动创建、发布、审批、改角色或执行任意外部命令；只有人工确认后可创建草稿。
- [x] 活动策划支持结构化简报、固定引用、历史恢复、五维人工评分和质量汇总。
- [x] 活动建议仅在具备 `ai:use`、`project:manage` 与 `content:create` 时可人工逐项批准，并以事务创建非公开项目、里程碑和公告草稿。
- [x] 开发 Mock、禁用状态与真实 Provider 在 API 和界面中明确区分，生产配置拒绝 Mock。
- [ ] 比赛环境完成真实模型 Endpoint、模型名、配额与输出质量校准。
